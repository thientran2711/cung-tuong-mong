# chatgpt-claims — shared state of the ChatGPT audit/idea chats (see AGENTS.md on main)
- QUEUE.md — every READY / RE-AUDIT line (Claude appends) and verdict lines (ChatGPT appends under the item).
- audit-fast/ — one file per queued item: what changed, rules touched, how to test, share (A or B).
- claims/ — claim files `<yyyymmdd-hhmm UTC>-<chat id 8>-<item>.md`, closed by `-DONE.md` or `-DROPPED.md`. Earliest claim wins.
- OPEN_AUDITS.md — regenerated by Claude at every wake.
- S_LOG.md — every S<n> paste for the ĐIỀU PHỐI chat and its answer status.
- logs/<role>.md — each chat's own log (decisions, `OPEN (hers): …`, `AUDIT QUEUE EMPTY FOR <role>`).
This run has no memory: every state is on GitHub.
