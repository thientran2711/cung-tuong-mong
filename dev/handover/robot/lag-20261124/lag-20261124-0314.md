## ANIM BUDGET (ORDER #8: how many animated figures a screen can hold, per format; synthetic loops of today's real figure pictures, no new art)

Method: fake LIVE figures = today's real full-body pictures (img/fig-consort-c01..c12-t1-a18.webp from the image CDN), drawn over the stage as 3 formats — **css** (2 transform layers per figure: whole-body breath + lower-body sleeve sway), **sprite** (12-frame sheet generated in the page, steps()), **webm** (alpha VP9 loop, 3 s, from anim-gen.py) — plus one action clip at a time every 10–20 s. CPU ×4 (like coop-lag), ANGLE SwiftShader (software GL: fps are box-bound, read the DELTA to the game alone). fx lite = «Hiệu ứng: Gọn» (OPT.fxon=false: isolates the figures from the game's own weather/particles); fx full = the game as she plays it. GPU Δ = GPU-process RSS (no VRAM counter in CDP). Cells = 20 s each.

### Rules (check against the numbers above before adopting)

- Pause every loop that is off screen (IntersectionObserver) and every loop while the tab is hidden (visibilitychange): `animation-play-state: paused` / `video.pause()`.
- Stagger loop phases (random negative `animation-delay`, different durations 3.1–4.7 s) so frames never change on the same tick.
- ONE real action clip (video / sprite burst) at a time on a screen; every other figure stays on the cheap idle layer.
- Idle layers: transform + opacity only (compositor), `will-change: transform` on the moving layer; never animate layout or filter.
- «Hiệu ứng: Gọn» (and weak devices) → still pictures; co-op sends state only, loops start after state applies.
