# C3-SEALS tools — how one seal is made (pilot: Hoàng thượng giận, 2 150 cr, 1 try)
Rules: owner OD 24/11 ~08:05Z + ~08:40Z (all animated like Thái hậu; ONE common prompt + frame, only the group text changes; same disc size). Magnific gpt-2-6 ONLY; LOOK at every frame sheet; images only on the CDN, never in git. Unit cost: A 135 + B 135 + OUT 940 + LOOP 940 + BACK 0 = 2 150 cr.
## Per seal (emotion k, group prefix P)
1. **Ref still** = the group's closest LIVE still (e.g. img/kit/emo-m-gian.webp, women base emo-gian.webp) → PNG 640 px lanczos → `creations_request_upload` (image/png) → `curl -X PUT -H 'Content-Type: image/png' --data-binary @ref.png <proxyUploadUrl>` → `creations_finalize_upload` (visible:false) → identifier = ref.
2. **A** (images_generate, mode gpt-2-6, 1:1, 2k, ref image): the Thái hậu act-A text `dev/art/emo-anim/groups/still_base/th-act-<k>-A.txt` with ONLY the person block swapped (see prompts_pilot/emp_gian_A.txt: who, hair/headwear, robe colour; disc colour of that emotion unchanged). Keep «Both eyes looking together», flat chroma green, no text, medallion a bit smaller. Women sets keep «Bare earlobes, no earrings.» (seal_gate S13). Only the EMPEROR wears yellow (OD 24/11): other groups pick another colour.
3. **B** (same, ref = that seal's own A): Thái hậu B text `dev/handover/reports/THACT1_tools/prompts/B_<k>.txt` (and the M2349 clear-action versions for the 13 redone seals, see THACT1.md §3) with the person block swapped (prompts_pilot/emp_gian_B.txt). Lean slightly OUT, small calm gesture, EXACTLY two hands.
4. **OUT** = video_generate slug bytedance-seedance-fast-2.0, 4 s, 1:1, 720p, withSoundEffects false, keyframes start=A end=B, prompt `…/prompts/out_<k>.txt` person-swapped (prompts_pilot/emp_gian_out.txt). **LOOP** = same, start=B end=B, `loop_<k>.txt`. (940 cr each.)
5. LOOK: creations_read A/B; download the clip URLs (`creations_wait` result), `ffmpeg -vf fps=2,scale=240:240` → 8-frame contact sheet with PIL → Read it. Redo only for a real fault (extra hand, face change, disc grows, shards); say so if a pattern repeats.
6. **Cut + scale** (this dir): `ffmpeg -y -i out.mp4 -vf reverse back_src.mp4`; `./cut.sh out out.mp4 <p><k>-out.webp`; `./cut.sh loop loop.mp4 <k>-loop.webp`; `./cut.sh back back_src.mp4 <k>-back.webp` (names must be <key>-out/-loop/-back.webp in ONE dir `.`; key = e.g. emp-gian). `python3 meas_raw.py . <key>` → `python3 apply.py . out_spec <key>` (THACT5 disc scale; needs disc_scale_spec.py in dev/art/emo-anim/ or edit the sys.path line) → `python3 meas_after.py out_spec <key>` must read rest ≈1.00 / peak ≈1.12 / loop ≈1.12 / back_end ≈1.00 / dev ≤0.01. disc.py needs only numpy+PIL.
7. **Names** (live): img/kit/emo-anim/<P>act-<emo>.webp (= LOOP), -out.webp, -back.webp + the 160 px still img/kit/emo-<P>act-<emo>.webp (rest frame of OUT, lanczos 160). <emo> keys: vui lo gian tinhtu an muu ghen buon so chan khochiu tutin tinhnghich binh dau hothen choang hon hanghai chuyentam hungkhoi (as img/kit/emo-th-act-*). Review copies first: img/_review/c3-seals/<P>/ (never delete, wipe at verdict).
8. **CDN**: put files under img/… in a checkout of main, then `python3 dev/site/cdn_sync.py img/_review/c3-seals/<P>` (auth is proxy-injected; each push rebuilds img/_index.json, ~70 s — batch per set). Never `git add img/`.
9. After EACH finished set tell Foreman C: set name, cr spent, sheet URL. Smoke of the wiring: `node smoke_wiring.js` (needs a built index.html in a worktree path; edit the path).
