## 1. How the sets were found (from code, not memory)
All scripts and outputs are in `dev/handover/reports/tier-audit/` (this branch). Every set has a file:line there.

2. `classify.js` — status per set: **CAP** > 3 options · **MERGE** ≥ 2 options with the same result kind AND near-equal size (±25 %; a same-kind group whose cost and gain both rise is a ladder = OK) · **FLAT** 2–3 options whose cost order ≠ result order or equal costs (the old «equal-value» design) · **OK** cost and result rise together. Weights for one rough scale: bạc ×0.1, Sức ×0.5, other stats ×1. Heuristic → every STEP 2 batch re-checks its rows by hand.
