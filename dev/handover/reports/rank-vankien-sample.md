Honest quality: 
- Edges are clean enough on dark/light at game size; SAM masks are soft at fine tassels/pearl strands (some clipped).
- BASE has big HOLES: segmentation only cuts what is visible, so skin under hair (forehead, behind ears), under sleeves/inner robe (neck-line, chest, arms) is empty. A hair swap shows white/transparent patches on the forehead and parting; an outfit swap with a different neckline shows gaps at neck/chest.
- Held items (fan, handkerchief) get sliced between base and outfit layers (white blobs where hands/sleeves overlapped).
- Pose/scale are identical so alignment is fine; different hair silhouettes leave stray old-hair pixels.
=> Pure cut-and-paste is NOT production ready. Needed: generate a bald, fully-nude-neutral... i.e. an inpainted BASE (body in a plain under-garment, face+neck+hands complete, no hair) once per person, and per-outfit/hair layers generated on that same pose. Magnific route: images_retouch (erase/replace with the masks) to inpaint the base, or generate each layer directly as a separate image with the same pose reference. Estimate extra ≈ 135–300 credits per person for the base, then layers ≈ 135 each.

## DRESS-UP PILOT (owner GO ~17:28Z) — sheet_dressup_pilot.jpg, sheet_dressup_close.jpg
Method (Magnific only): (1) BASE per person by images_generate gpt-2-6 (face ref + v4 pose ref): ivory low bodice + plain skirt, low flat knot, hands clasped EMPTY. c01 + c02 done. (2) OUTFIT / HAIR / ITEM on the c01 base by images_retouch mode=edit (whole-image edit with the v4 figure as reference image). (3) Each layer cut with images_segment (SAM 3.1 prompt "the … clothing", "hair", "flower hairpin", "pink flower crown", "the lilac handkerchief"; box prompt for the fan) → alpha, composed locally (PIL). Edit output is 1365x2048 (same 2:3), bases 2048x3072 → resized to match.
Result: works at game size. Swaps proven: c01+Quý phi outfit+Tần hair+fan; c02+Tần outfit+Quý phi hair+handkerchief; c01+Tần outfit+Quý phi hair; c02+Quý phi outfit+Tần hair+fan. Face/neck/chest/hairline are complete (no holes) because they come from the base.
Honest problems:
- Outfit layer has holes at the clasped hands (SAM stops at hands) → base hands show through: fine, but sleeve-over-hand cannot be layered; hands are always on TOP of nothing, ok for clasped pose only.
- Base ivory short sleeves/bodice peek out at the shoulders/neckline under a smaller outfit (Quý phi shoulder shows white strips). Fix: base underlayer should be skin-coloured/nude-neutral or a thin tight inner layer, or outfit layer must be drawn with oversize shoulders.
- Hair layer incomplete: SAM "hair" returned only the visible bun part; the base's flat knot stays under the new hair (Quý phi "tall bun" came out as a flower headband; Tần bun fine). Need hair-on-bald-head base (hair as pure add-on) or a mask that includes the whole hair region incl. old knot.
- Edit mode is NOT pixel-exact: face drifted slightly (face-region differs a little between edits) and one hair edit also changed the clothes (redone, +80). Seams visible where layer colour/lighting differs from base (soft edges, 1 px blur).
- Fan too big for the hands and sits on the chest; item layers need to be drawn per size. c02 base differs slightly in proportion from c01 (head smaller, hands lower) so c01 layers on c02 are approximate: works for same pose template only.
- Pose fixed for all: that is the price of swapping. Free pose/other hands need new layers.
Credits (observed): base 135 each (2 = 270); outfit edit 80 + SAM 35 (+80 redo for 2 of them); hair edit 80 + 35–70 masks; item 80 + 35. Whole pilot ≈ 1,400 credits (2 bases, 2 outfits, 2 hair sets, 2 items, 12 masks, 3 redos). Steady state per NEW outfit ≈ 115, per hair ≈ 150, per item ≈ 115, per person base ≈ 135–270, vs 135–190 for a whole figure: layers pay off only when ≥~3 mix-and-match combos are shown per person.
Recommendation: dress-up = base + OUTFIT layers (clean win), hair/pins as separate layer only with a bald/under-cap base; keep items inside the outfit layer when possible; skin-toned underlayer base.
