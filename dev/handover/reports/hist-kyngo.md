## (b) Which need a choice; both sides stay equal (laws 2, 3)
Needs a choice: #3 jade (return vs keep), #4 casket (report vs keep), #6 beads, #12 omen (publish vs keep quiet), #15 healer (follow him vs keep the secret), #22 letter (use vs return), #7 wish, #1 recipe vs ally. The rest are plain gain, which law 3 allows (cost = the khắc spent).
Patterns that stay equal and each have a gain and a loss:
- Return vs keep: Return = relation +big, Bạc 0; Keep = Bạc +big, relation −small, the owner may investigate (real NPC searches, two-way law 1).
- Public vs quiet: Public = Danh +, a rival notices; Quiet = Tâm cơ/secret edge +, no Danh.
- Take the object vs take the person: object = item now; person = ally later (slow, bigger).
- Reward budget is one core: both branches cost the same BAL "value points"; the designer prices them from BAL so no branch is cost-only.
- Never a hidden better choice: show only costs on the cards, results hidden, as j97 does; the reward value equality is checked by a bot script (law 2).

## (c) How other games pace rare random events (reference), and the answer to owner 03:25Z
Common techniques (known from game design practice): (1) **pity timer / soft pity** (gacha: Genshin-style, Fire Emblem Heroes): probability rises with each miss, resets on hit; (2) **bad-luck protection / streak breaker** (Diablo, Path of Exile drop tuning); (3) **per-place weights**: each location has its own rare table (Stardew Valley, Animal Crossing: Nook mile events, Fire Emblem support events); (4) **cooldown + once-per-life**: a rare cannot repeat for N turns, and each unique can be met only once (Crusader Kings events with `cooldown`, Sims "opportunity" cards); (5) **rarer as rank rises**, either by lowering the pool or lifting a prerequisite (Dwarf Fortress strangers, CK "random encounter" weights vs. rank); (6) **telegraphing**: faint sign beforehand (weather, a bird, a fragrance) so the player feels fate, not a coin toss (Stardew "something stirs").
Palace-game ones: drama-game adaptations (Chinese court-life mobile games like 《宫廷计》 and the Diên Hi-licensed ones) use daily "tình cờ" cards that rise with idle days. (trope; names from memory, no source printed.)

Recommended shape (so a normal player meets about one every few weeks, no double gate):
- ONE gate only: she walks/acts at a place in a buổi where some encounter has a real candidate NPC + real object right now. No hidden stat gate before the roll. Stats and rank change WHICH encounter and how big, not WHETHER the roll happens.
- Pity timer: base chance per eligible buổi p0; after each buổi without a kỳ ngộ add a step; after a hit reset and start a cooldown. Numbers go in BAL (law 4). Bot must measure: expected gap in game weeks, target about one per 3–5 game weeks (12–20 buổi); report mean, p10, p90, and the share of lives that see zero.
- Per-place weights: gardens, Phật đường, cold palace, kitchen each own a table; weather and festival add a bonus, not a gate.
- Law 5: higher rank ⇒ larger rewards but fewer candidates and a longer cooldown; the early life is not starved.
- Law 7: she sees only ladder words on odds, never the %. A faint omen sign (weather/fragrance) can precede a hit.
- Once per life per encounter id (plus Sổ luân hồi line like j97). Never re-rolled behind her back.
- Measurement order from owner OD 03:25Z: first measure how often candidates exist (eligibility), then set the roll from it; if eligibility is nearly 100 % the roll can sit near the story rares (9–13 %), if lower the pity makes up the gap.

## (d) How NPCs can meet the same kỳ ngộ (law 1)
- The same table runs for each consort/maid NPC on their own buổi in the background, with the same pity rule and same object ledger.
- Object scarcity is shared: if an NPC took the casket, it is gone for her and the ledger shows the new owner (law 6c); if she keeps the jade, the owner NPC searches and may accuse (two-way).
- NPC outcomes show in the news/gossip lines ("nghe nói {x} được cao nhân chỉ điểm") so she can trace who got what; an NPC with a new ally or recipe uses it the way she would.
- NPCs with a kỳ ngộ gain the same reward tier, so nothing is player-only; rate parity per rank band keeps it fair for bot measurement.
