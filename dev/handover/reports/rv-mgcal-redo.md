## FAIL (1): stale tries are still in the result code
`mgCalCode(r)` (jmgcal.js, the «Mã kết quả» row + «Chép mã») = every record in rec(): `Object.keys(r).filter(k=>r[k]&&r[k].b!=null)`, i.e. it still contains the PRE-FIX tries. With the seeded record my probe reads «CTM-CAL … mua:8/5@11/20/2026 huong:8/5@… td_dung … chai … hoadien …» although those kinds are now «chưa thử». That code goes to the coordinator / mgcal_apply.py → cal.k, so a try taken on the broken board would be applied again — exactly what the cal-p2b note forbids («a first try taken on a BROKEN board is dropped when that board is fixed»). Same for the «Mã kết quả» row visibility (`Object.keys(r).length`).
Fix (jmgcal only): build the code from `Object.keys(r).filter(k=>ok(r,k)&&r[k].b!=null)` (and show the «Mã» row only when that list is non-empty); add a check to mgcal-redo.js: code contains dauho (tried after) and NOT mua / huong / td_dung / chai / hoadien / den / banh.
