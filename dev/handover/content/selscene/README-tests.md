## Scoring note for SELSCENE (weights belong in BAL, not in data — law 4)
score(option, royal) = Σ over the option's `values`: + w_match if the virtue is in the royal's chữ trọng (`trongOf`, 2 of 13), − w_clash if it conflicts with one (CONF below), plus a small nết term. Use the royal's REAL trọng this life; the `reacts` table is the fallback / nết term:
- `reacts` rule (generated by the same script for every row; change `LIKE`/`CONF` there and regenerate): a nết LIKES a short list of virtues (E 2, T 4, H 2–3: e.g. E.nhantu Nhân+Khiêm, E.hieuthao Hiếu+Lễ, T.nghiem Lễ+Cần+Liêm+Sỉ, H.ThatTha Tín+Nghĩa+Hiếu) and DISLIKES the conflicting partners: Hiếu↔Trung, Tín↔Nhân, Lễ↔Nghĩa, Nghĩa↔Liêm, Sỉ↔Khiêm, Sỉ↔Nhân, Trí↔Đễ, Cần↔Kiệm. Net +1 → "+", net −1 → "−", else the key is omitted (neutral).
- Result: the same answer pleases one royal and displeases another (validated: no universal best, ≥3 of 4 options are best for some nết, no option dominates another for all nết).
- `reacts` keys are limited to the asker's group: E.* / T.* / H.* (`ma` uses H.*; `any` hành xử uses all three groups of the royals present). Pass-through of the 2 v1 extra H keys (`H.HamVui`, `H.NongNay`) only where a row had them.
- `gain`/`loss`: ONE side-effect key each, equal step `V` for all four options (laws 2/3, same V as v1). Keys now never use `fav*` (thiện cảm comes from the score match) — only duc, tai, tamco, face, friend.mate, fav.ma, time, bac, grudge.rival. `bac` and `fav.ma` still PROPOSED new BAL keys (MAIN adds or remaps). Values are step counts, never printed before the pick.
- NO GUIDANCE (OD 23/11 ~23:40Z/~23:43Z): the selection scene prints only `prompt`/`incident`, `cue` and the four `text` lines. The RESULT card after the pick shows thiện cảm ± with that royal and the `gain`/`loss` rows (kit result rows).
- `lo` (origin rank gate, law 5) and `fit` (royal nết draw weights, §8.3) unchanged from v1. `asker`: E/T/H, `ma` (Nội vụ phủ ma ma; "Nô tì" wording), `any`.
